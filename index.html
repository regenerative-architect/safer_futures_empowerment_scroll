🧭 Agency-first

The OS suggests options, tradeoffs and protective factors. It does not diagnose, coerce, shame, rank a person’s worth or make consequential choices for them.

🛡️ Safety by design

Private notes default to local storage. Public sharing, strangers, location tracking and hidden telemetry are deliberately absent.

🔌 Useful offline

The core guides, planner, checklists, logs and exports work without AI. Hosted deployments can be installed as a PWA after first successful load.

Zero-Harm / Anti-Inversion

Protective systems can become harmful when they surveil, shame, punish, manipulate, expose private data, or turn “safety” into control. This app therefore favors consent, reversibility, minimal data, age-appropriate trusted support, transparent logic and clear limits.

Why deterministic first?

For a safeguarding tool, predictable logic is a feature. You can inspect the rules, run the same plan again, and use the app even when local AI, WebGPU or the network is unavailable. AI can be added later as a clearly labeled optional drafting layer, never as the source of truth.

Production multiplayer safety gate

  • Age-appropriate identity and consent model.
  • Moderation, reporting, rate limits and abuse response.
  • No public sharing of precise location, school schedule or sensitive personal data.
  • Durable membership/recovery layer when shared state matters.
  • Clear transport abstraction and reconnect/version rules.

The supplied code intentionally stops short of anonymous internet P2P. A production WebRTC/Trystero adapter belongs behind these controls.

About this build

      

        

          
What this is

          
A practical learning and planning toolkit that translates ten broad youth challenges into small, inspectable actions, protective-factor prompts and locally saved artifacts.

        

        

          
What this is not

          
It is not a therapist, doctor, emergency service, financial adviser, legal adviser, social-service eligibility engine, political persuasion system or covert monitoring tool.
